# SBI ATM Management System

A Python-based ATM Management System project built using 
Object-Oriented Programming (OOP) concepts.

## About Project

This project simulates a real ATM system where users can create
accounts, login securely using PIN authentication, perform banking
operations, and view transaction history.

The project is designed with multiple classes and files to maintain 
clean code structure and better understanding of software design.

## Features

-Create User ID
-User login with PIN authentication
-Deposit money
-Withdraw money
-Check balance
-View transaction history
-Admin management features
-Data storage using JSON file
-Input validation
